# SIH 2026: AI-Based Detection and Classification of Industrial Fires and Persistent Thermal Sources

> Autonomous geospatial intelligence system integrating NASA FIRMS thermal telemetry, OpenStreetMap infrastructure polygons, ESA WorldCover land use data, and Sentinel-2 satellite imagery.

---

## 📑 Core Documentation
- **[Strategic Problem Analysis & Architecture Blueprint](file:///c:/Sih_2026/STRATEGY_AND_PROBLEM_ANALYSIS.md)**: Full breakdown of stakeholders, root causes, urgency, the 15-solution impact/effort matrix, and the 4 core technical levers.

## 🎯 Primary Deliverables
1. **Classification & Segregation Engine:** Machine learning pipeline to distinguish accidental industrial fires from persistent industrial heat sources (flare stacks, smelters), forest fires, agricultural residue burning, and mining.
2. **GIS-Based Command & Visualization Platform:** Interactive map overlaying real-time thermal anomalies, asset boundaries, historical baselines, and actionable HazMat incident dispatch cards.
